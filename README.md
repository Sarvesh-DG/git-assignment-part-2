# Country Capital API

## Description
Country Capital API is a Python and Flask based API that returns the name of the country if the capital city is provided.

It uses the ASGI server Uviorn to serve the API

A microservice endpoint for this API available that can be used by any organization to consume this API

## Prerequisites

-Python
-Flask
-Uvicorn

## Running the Application

Start the application using Uvicorn server
The API will then be available for requests

## API Enpoint 

The microservices are available at :

https://example.com/country-capital/<query-params>
